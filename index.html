COMMON QUESTIONS

Good to know.

This is a classroom website prototype, not an official registration or course-policy portal.

Does this chatbot use real AI?

Once connected to the production n8n Chat Trigger, visitor messages are processed by our configured AI Agent. Until then, the chat is unavailable.

Can I ask about official course fees?

This sample site has no verified fee database. It will not invent official fees or schedules.

How do we connect it to n8n?

Set N8N_CHAT_URL in chat-config.js to the public production Chat Trigger URL, then deploy the website and configure the exact website origin in n8n.

Does this chatbot save enquiries?

Messages will be processed by our n8n workflow after integration. We have not configured automatic lead storage in this sample.
